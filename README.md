# Reelax Dashboard Assignment

A responsive analytics dashboard built using React and Tailwind CSS.

## Features

- Responsive sidebar navigation
- Dashboard analytics cards
- Revenue chart with Recharts
- User management table
- Reports section
- Settings page
- Mobile responsive layout
- Interactive UI components

## Tech Stack

- React JS
- Vite
- Tailwind CSS
- Lucide React
- Recharts

## Installation

Clone repository:

git clone <your-repository-url>

Move into project:

cd figma-assignment

Install dependencies:

npm install

Start development server:

npm run dev

Build production:

npm run build
